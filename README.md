# 私密密码库

这是一个可部署到 GitHub Pages 的静态密码库。密码条目以主密码派生的 AES-GCM 密钥加密后，仅存入当前浏览器的 `localStorage`；GitHub 只会保存网页代码。

## 手机使用与安装到桌面

部署到 GitHub Pages 后，用手机浏览器打开 HTTPS 地址：

- **Android（Chrome/Edge）**：点击网页右上角的“安装到桌面”，或在浏览器菜单中选择“安装应用”。
- **iPhone（Safari）**：点击底部“分享”按钮，向下滑动后选择“添加到主屏幕”。iPhone 上不会出现网页内的安装按钮，这是 Safari 的限制。

安装完成后它会像普通 App 一样在桌面打开。每台设备的数据彼此独立；需要迁移条目时，在旧设备导出加密备份，再在新设备导入。

## 本地使用

直接用浏览器打开 `index.html` 即可。首次使用设置主密码，之后用同一主密码解锁。

## 发布到 GitHub Pages

1. 在 GitHub 新建**私有仓库**（尽管不会上传密码数据，私有仓库仍更合适）。
2. 上传本文件夹中的 `index.html` 和 `README.md`，不要上传任何导出的备份文件。
3. 在仓库 **Settings → Pages** 里，选择从 `main` 分支的根目录部署。若此密码库在一个大仓库的子目录中，请选择该目录，或单独新建仓库。
4. 使用 GitHub Pages 给出的 HTTPS 地址访问。

## 重要安全说明

- 主密码无法找回；忘记后现有条目无法解密。
- “导出加密备份”可迁移或备份数据。备份文件仍需要主密码才能打开，但请妥善保管，且不要提交到 GitHub。
- 若设备有他人可用，请使用完点击“锁定”，并启用系统账户密码/磁盘加密。
- 更高安全需求或需要跨设备自动同步时，建议使用成熟的密码管理器，例如 Bitwarden 或 1Password。
